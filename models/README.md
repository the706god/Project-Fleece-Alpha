# Model Directory

This directory houses the GGUF model weights for Project: Fleece Alpha.

### Automated Setup
The engine automatically downloads the verified GGUF weights on first launch.

You can also pre-download the weights manually at any time by running from the repository root:
```bash
python setup_models.py
```

### Model Specifications
- **Model:** Qwen 2.5 Coder 3B Instruct
- **Quantization:** Q4_K_M
- **Filename:** `model.gguf`
- **Source:** Hugging Face (`Qwen/Qwen2.5-Coder-3B-Instruct-GGUF`)
